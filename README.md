# Optimized SHARE protocol

This repo houses the code used in the analysis written in the optimized SHARE protocol manuscript. 

### For creating Fig 4, Supp Fig 2 and Supp Fig 3, please run 
- [scRNA-preprocess.ipynb](https://github.com/broadinstitute/sharev2-analysis/blob/main/notebooks/scRNA-preprocess.ipynb)
- [scATAC-preprocess.ipynb](https://github.com/broadinstitute/sharev2-analysis/blob/main/notebooks/scATAC-preprocess.ipynb) and then
- [main-analysis.ipynb](https://github.com/broadinstitute/sharev2-analysis/blob/main/notebooks/main-analysis.ipynb)

### For creating Supp Fig 1, please run 
- [round1-distribution.ipynb](https://github.com/broadinstitute/sharev2-analysis/blob/main/notebooks/round1-distribution.ipynb)

For any questions and data requests, please open an issue on the repo.
