# SHAREv2 data processing and analysis

This repo houses the code used in the analysis written in the optimized SHARE protocol manuscript. 

For creating Fig 4, Supp Fig 2 and Supp Fig 3, please run scRNA-preprocess.ipynb, scATAC-preprocess.ipynb and then main-analysis.ipynb

For creating Supp Fig 1, please see notebooks/round1-distribution.ipynb 

For any questions, please open an issue on the repo.
